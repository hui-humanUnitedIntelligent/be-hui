Accessibility Statement

HUI is committed to making its website accessible to all people.

Our commitment

HUI is committed to designing an accessible website. We are working to ensure that all people can use the website — regardless of individual abilities, technical prerequisites, or assistive technologies.

The website is continuously being improved in terms of accessibility.

Measures taken

The following aspects of accessibility are taken into account on the HUI website:

Keyboard navigation

Navigation and all interactive elements can be operated using the keyboard. Links and buttons are accessible via the Tab key and can be activated with Enter.

Contrast

Text colours are matched for sufficient contrast against the background. The colour palette used (cream, dark navy, teal, coral) is chosen so that text remains clearly readable.

Responsive display

The website adapts to different screen sizes — from desktop to iPad to smartphone. Content remains readable and navigable on all devices.

Semantic structure

The website uses semantic HTML (heading hierarchies, lists, correct landmark roles) to enable logical orientation for screen readers.

Alt texts

Images and graphic elements are provided with alt texts where they are content-relevant. Decorative elements are appropriately marked for assistive technologies.

Reduced motion

The website respects the system setting "Reduce Motion" (prefers-reduced-motion). Animations are reduced or disabled when the setting is active.

Screen reader compatibility

The website is tested with common screen readers. ARIA labels are used where semantic HTML alone is not sufficient.

Formal audit

A formal accessibility audit (e.g. according to WCAG 2.1 or BITV) has not yet been conducted. The measures mentioned above are based on best practices and ongoing self-review.

Known limitations

Despite the aim of full accessibility, there may be areas that are not yet fully accessible. We are continuously working on improvements.
